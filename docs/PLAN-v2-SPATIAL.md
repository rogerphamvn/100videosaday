# Plan v2 — Spatial Creative Studio

20/10/2026. User steering: giao diện hiện đại, đẹp, dễ sử dụng; dùng skill 3D/motion graphic để tạo và định hướng UI/UX.

## Objective

Revise visual direction without changing product evidence rules, model/API contracts or backend scope. Deliver three new raster UI concepts, a motion/design contract and one local interactive CSS3D visual prototype to demonstrate meaningful transitions. Keep v1 files/archive and original review intact; v1 approval/review does not transfer to v2.

## Representation

Spatial interface illustration: product source → motivator → concept → hooks → remix. Flat, readable DOM forms and inspectors sit around a dark spatial canvas. CSS perspective cards illustrate creative relationships; they are not product meshes or a physics model. No automatic photo-to-3D product reconstruction.

## Ownership and sequence

1. product_prd: docs/DESIGN-v2-SPATIAL-STUDIO.md and docs/MOTION-CONTRACT-v2.md.
2. prompt_contracts: prototype-v2/ and self-review only; no network, paid generation, API or deployment.
3. Root: mockups/v2/, plan, gallery/review entry, browser observation and integration.
4. architecture_spec: independent v2 evidence review, inspect pixels and review behavior evidence, scoped verdict.

Image mockups establish visual direction; prototype demonstrates the interaction vocabulary and may simplify the mockups' lighting/material. Neither is the complete web app. Current user request authorizes a visual update; no plan-approval pause.

## Acceptance

- Three separate coherent desktop concepts with demo/API disconnected labels.
- 3D makes lineage, selection and branching easier to understand; no continuous spinning or decorative particles.
- Key controls and body text remain planar, readable and keyboard-operable.
- Prototype has meaningful focus changes, list mode, reset and batch preview; no paid run.
- User motion toggle and live prefers-reduced-motion produce static equivalently informative states.
- Inspect actual 1440px and 390px browser pixels and controls, record observed/not observed separately.
- New review and hashes bind v2 only; preserve v1.

## Explicit limits

No backend/provider integration, Cloudflare deployment, true product mesh or market-performance claim. Built-in ImageGen cannot select/verify model version 2.5. CSS3D proof is a spatial UI prototype, not Three.js/WebGL output. Motion is demonstrated through actual web interaction rather than exported video.
